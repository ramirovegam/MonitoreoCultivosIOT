# 🌱 Sistema IoT de Monitoreo de Humedad para Plantas

Proyecto desarrollado con **Arduino** y **Python** para monitorear en tiempo real la humedad del suelo de una planta. El sistema captura los datos mediante un sensor de humedad conectado a Arduino y los envía a una interfaz gráfica desarrollada en Python, donde se visualiza el estado de la planta, el nivel de humedad y el consumo estimado de agua.

## 🚀 Características

- Lectura de humedad del suelo mediante sensor analógico.
- Comunicación entre Arduino y Python por puerto serial.
- Interfaz gráfica amigable para monitoreo en tiempo real.
- Visualización del porcentaje de humedad.
- Indicador visual del estado de la planta.
- Registro del consumo estimado de agua.
- Sistema escalable para integración con plataformas IoT.

## 🛠️ Tecnologías Utilizadas

- Arduino UNO
- Sensor de humedad de suelo
- Python
- Tkinter / CustomTkinter
- Comunicación Serial (PySerial)

## 📷 Capturas de Pantalla

### Interfaz Principal

## 📋 Funcionamiento

1. El sensor mide la humedad del suelo.
2. Arduino procesa la lectura analógica.
3. Los datos se envían mediante comunicación serial.
4. Python recibe la información en tiempo real.
5. La interfaz actualiza el porcentaje de humedad y el estado de la planta.

## 🎯 Objetivo

Desarrollar una solución IoT para el monitoreo inteligente de cultivos o plantas domésticas, permitiendo conocer el estado de hidratación y facilitar la toma de decisiones sobre el riego.
